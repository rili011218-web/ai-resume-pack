# 🗣 面试话术指南：简历上的每条经历都要扛得住追问

> 简历是面试的"提纲"——面试官 80% 的问题都从简历上出。写上去的每条经历，你都要能讲 1 分钟、扛得住 3 轮追问。

## 一、三条铁律

1. **能讲才写**：写进简历的内容 = 你愿意在面试里被深挖的内容。讲不出的细节，要么补课弄懂，要么从简历上降级/删除
2. **停在"流程 + 格式 + 角色"层**：讲经历时描述"做了什么、用什么方法、你负责哪部分"，不堆砌编造的细节——细节越多越容易前后矛盾
3. **被问住就承认边界**：真不会就说"这块我当时接触不多 / 主要是我同事负责，我了解一部分"——对新人 100% 合理，硬编才会穿帮

## 二、一分钟角色定位（背熟你的开场白）

结构：**背景一句话 + 与岗位相关的经历 + 为什么投这里**

> 模板："我是【学校】【专业】的【本科/硕士】，【与岗位相关的经历概括】。这次投【岗位】，是因为【两点原因：兴趣+能力匹配】。"

要点：别背长简历，开场 1 分钟把最相关的 1-2 段经历讲出来即可。

## 三、高频问题应对表

| 问题 | 应对 |
|---|---|
| 你这段实习具体做了什么？ | STAR 讲一段（见下），讲"流程+角色" |
| 为什么要做这个项目/这段实习？ | 讲动机（兴趣/补能力短板/观察行业） |
| 最大的困难是什么？ | 讲一个真实小挫折 + 你怎么解决（别讲没困难） |
| 有什么失败经历？ | 讲失败 + **学到了什么**（成长型回答，高频题！） |
| 为什么只有 X 个月/有空窗期？ | 时间安排/备考/家庭原因，两三句带过，不回避 |
| 你还有什么问题？ | 问 1-2 个具体问题（团队做什么/实习生参与度/考核标准） |

## 四、STAR 讲故事模板

- **S 情境**：当时是什么项目/任务，背景一句话
- **T 任务**：你负责哪部分（说清边界，别揽全组功劳）
- **A 行动**：具体做了什么（用了什么方法/工具），2-3 步
- **R 结果**：结果如何——**结果别吹大**，"按期交付并被采用"就是好结果

> 练习方法：把简历每条经历写成 60 秒 STAR 稿，找 AI 模拟面试官连续追问 5 轮，答不上来的地方就是你要补的课。

## 五、行业惯例可以成为"专业的回避"

某些行业有真实的保密文化，被问到客户/项目细节时，合理回答：

> "这个项目涉及客户保密约定，不方便讲太细。我主要参与的是【访谈记录/资料整理/数据分析】这部分基础工作。"

适用场景：咨询、投资、审计等确实签 NDA 的行业。**前提是你真的理解"那部分工作是什么"**——所以面试前要把岗位的日常工作流程弄清楚。

## 六、面试前检查清单

- [ ] 简历每条经历都能讲 60 秒 STAR
- [ ] 简历里每个数字都有可解释的口径（"几千用户"到底几千？）
- [ ] 能一句话讲清每段经历的"组织/公司是做什么的"
- [ ] 能回答"为什么投我们公司/岗位"
- [ ] 简历、招聘平台、自我介绍三处口径一致
- [ ] 准备 2 个反问面试官的问题
- [ ] 模拟追问 5 轮（用 AI 或朋友）
