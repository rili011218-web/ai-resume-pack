# 🌐 英文简历支持

> 目标读者：需要投外企 / 外资 / 海外岗位，或公司要求英文简历的同学。
> 配合 `generator/sample_en_config.json` 使用——生成器本身支持英文：**只需把模块标题和内容写成英文**。

## 一、结构差异（中英文简历不同点）

| 中文简历 | 英文简历 |
|---|---|
| 通常附照片 | **欧美通常不放照片**（避免歧视争议）；亚洲外企可放 |
| 写出生年月/性别 | 欧美不写 age/gender/marital status（法律敏感）；写不写看公司属地 |
| 求职意向一段话 | Objective 一句话或省略（简历头部直接给 contact + LinkedIn） |
| 模块名中文 | EDUCATION / EXPERIENCE / PROJECTS / LEADERSHIP / SKILLS / AWARDS |
| 时间格式 2023.06 | Jun 2023 – Aug 2023 |
| 均分 85/100 | GPA 85/100 或换算 4.0 制（**注明换算方式**，如 3.5/4.0） |

## 二、英文简历通用结构（模板骨架）

```
Name
City, Country | Phone | Email | LinkedIn(可选)

EDUCATION
University — Degree, Major          Sep 2025 – Jun 2027
· Relevant coursework: ...
· Honors/Awards: ...

EXPERIENCE
Company — Position                  Jun 2023 – Aug 2023
· Action verb + what you did + result（每条约 1 行）

PROJECTS / LEADERSHIP
Project/Org — Role                  Sep 2022 – Jun 2024
· ...

SKILLS
Tools / Languages / Certificates
```

## 三、高频动词库（写经历用"动词开头"）

**分析研究**：analyzed, researched, evaluated, assessed, benchmarked, forecasted
**数据量化**：built, developed, automated, streamlined, processed, modeled
**增长市场**：launched, grew, drove, optimized, acquired, retained, boosted
**协作领导**：led, coordinated, organized, facilitated, liaised, partnered
**产出交付**：delivered, drafted, produced, presented, published, implemented

## 四、中英对照常用表达

| 中文 | 英文 |
|---|---|
| 负责/主导 | Led / Owned / Drove |
| 协助 | Supported / Assisted (with) |
| 参与 | Participated in / Contributed to |
| 数据驱动决策 | data-driven decision making |
| 转化漏斗 | conversion funnel |
| A/B 测试 | A/B testing |
| 冷启动 | cold start (product launch) |
| 访谈纪要 | interview notes / meeting minutes |
| 初步方案 | preliminary proposal / initial draft |
| 全渠道营销 | multi-channel marketing |
| 净现值 | Net Present Value (NPV) |
| 敏感性分析 | sensitivity analysis |

## 五、要点

- **每条经历动词开头、过去式、带量化结果**："Led cold start, growing users from 0 to 3,000+ in 3 months"
- 每条约 1–2 行，别写成长句；要点用"动词 + 做了什么 + 结果/数字"模板
- **数字统一口径**：3,000+ / RMB 1.2M / 40% 提升——和中国简历保持同一数字，别两版不一致
- 专有名词（课程名、项目名）首次出现给英文翻译，别硬翻
- 没把握的英文表达，让 AI 逐条润色，再让英文母语者或 AI 校对一遍
